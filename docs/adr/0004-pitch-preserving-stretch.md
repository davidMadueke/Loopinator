# Pitch-preserving stretch, no live key transpose

Sunday needs a live Target BPM that does not turn the kit into chipmunks. Playback time-stretches while holding pitch, clamped to ±20% of Original BPM. The Key +/- buttons drawn on the Figma play screen do not ship in v1. Transposing means a second audio engine, and it sounds bad on drums. Key stays metadata. High-confidence Key detection may fill that metadata; low confidence or no result leaves No Key, and a Track whose Key is No Key never gets key-change UI.
