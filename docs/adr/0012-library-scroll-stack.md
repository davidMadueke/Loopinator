# Library panel scroll-stack, not modal overlay

Early sketches treated the Library as a modal over the Play screen. Editors need to browse Tracks and edit Setlists without stopping a loop that is already running through the PA. The Library panel stacks full-width above the Playback frame in the same scroll column, with Tracks and Setlists as separate tabs. Playback keeps going while either tab is open, and the musician scrolls down to reach the player again. Setlist editing stays inside the Setlists tab, reached from Create new or Edit on a row.
