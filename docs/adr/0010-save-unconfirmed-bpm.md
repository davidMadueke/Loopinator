# Save unconfirmed detected BPM

Church OS says a human confirms ambiguous writes. Loopinator bends that for tempo. Detection often misreads sparse percussion, but blocking Save behind a typed BPM stops an Editor uploading a loop they have not measured yet. The upload modal saves the detected value as an Unconfirmed BPM, flags it in the Library, and lets an Editor correct it later. Time-stretch still works, so a wrong Original BPM shows up as a Target BPM that feels off rather than a Track nobody can play.
