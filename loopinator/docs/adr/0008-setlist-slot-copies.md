# Setlist slot copies performance settings, Track keeps defaults

Save for everyone on a Setlist copies Loop region, Target BPM, and Transport fade onto that one Setlist slot. Sunday1 can tighten a bed while Rehearsal keeps playing the old one. Display name, Key, and Time signature belong to the Track. Save for everyone on `/t/{id}` writes the Track default that new slots inherit. Playback reads the Local override first, then the Setlist slot, then the Track default.
