# Setlist slot copies performance settings, Track keeps Track name

Save for everyone on a Setlist copies Loop region, Target BPM, Transport fade, Key, and Time signature onto that one Setlist slot. Sunday1 can tighten a bed, or show a different Key or Time signature, while Rehearsal keeps the old copies. Track name belongs to the Track. Save for everyone on `/t/{id}` writes the Track default that new slots inherit. Playback reads the Local override first, then the Setlist slot, then the Track default.
